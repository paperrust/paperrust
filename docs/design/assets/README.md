# PaperRust – Logo-Dateien (Konzept A „Eselsohr“)

| Datei | Verwendung |
|---|---|
| `paperrust-logo.svg` | Primär, auf hellem Grund (mit Rost-Struktur, ab 64 px) |
| `paperrust-logo-inverse.svg` | auf dunklem Grund (Eisen/Graphit) |
| `paperrust-logo-mono.svg` | einfarbig, Farbe über CSS `color` (currentColor) |
| `paperrust-app-icon.svg` | App-Icon 512 (Desktop/Store) |
| `favicon.svg` | Favicon 16/32 (flach) |

Farben: Eisen `#1F1A17`, Rost `#B7410E`, Rost hell `#E07A3F`, Papier `#F4EFE6`.
Wortmarke: Archivo ExtraBold, „Paper“ in Eisen, „Rust“ in Rost. Für den Druck die Wortmarke noch in Pfade umwandeln.
Schutzraum: rundum mindestens Breite der Ecke. Kein Zahnrad, nicht drehen/verzerren, Ecke immer in Rost.
