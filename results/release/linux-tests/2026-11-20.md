## Fehlschlag

`pl-documents-write files::tests::checked_paths_reject_escape`: Der Test erwartete, dass
`"..\archive\0000042.pdf"` als Pfad-Ausbruch abgelehnt wird. Unter Linux ist `\` kein Trennzeichen, sondern
ein gewöhnliches Zeichen im Dateinamen; der Name bleibt innerhalb des Medienordners. **Kein Sicherheitsfehler,
sondern eine Windows-Annahme im Test.** Korrektur: diese Prüfung nur unter Windows, zusätzlich derselbe Fall
mit `/` auf allen Systemen. Unter Linux (WSL, x86_64) nachgeprüft.
